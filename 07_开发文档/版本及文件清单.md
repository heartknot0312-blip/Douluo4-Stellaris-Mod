# 版本及文件清单

本工程沿用原相对目录，以保证 import、媒体生成与打包脚本解析到同一份源码。README 与本目录提供按职责划分的索引。

| 交接类别 | 实际路径 |
| --- | --- |
| Mod 完整源码 | src/engine.mjs、schema.mjs、host.mjs、command.mjs 等，scripts/，test/ |
| 前端及组件 | src/atlas.mjs、ui-model.mjs、console-view.mjs、flightdeck.mjs、desk-panels.mjs 等 |
| 前端预览工程 | scripts/preview.mjs、handoff/preview.mjs、outputs/星海导航-预览.html |
| UI 组件与样式 | src/atlas.css、flightdeck.css、command.css，src/atlas-style.generated.mjs |
| 图片与资源 | assets/gray/v5、assets/hangar、assets/fonts、src/*generated.mjs |
| 数据与配置 | model.json、bindings.json、prompts/、package.json、.env.example |
| 交接与验证 | 07_开发文档/、handoff/source-inventory.json、outputs/manifest.json、outputs/前端预览证据.json |

## V9 安装与预览

- 当前工坊版本为 9，前端版本为 9.0.0，后端数据格式为 1.0.0。安装与预览均提供默认入口和带 v9 的版本副本。
- 带 v8 的安装器和预览对应浅色界面快照，可通过 Git 标签 `v8-dev-snapshot` 查阅该版本的源码。

## V8 快照归档依据

- 归档前工作目录没有 Git 历史。判定依据是工坊作品包 work.version=8、manifest 的 workshopVersion=8 与 frontendVersion=8.0.0，以及实际打包入口引用的四层 CSS，最后一层为 pearl.css。
- 已将 manifest 所列产物逐个计算 SHA-256；预览证据所列 14 个模块与实际源码逐项匹配。版本选择没有依赖文件名排序或修改时间。
- 旧 V7 安装包、旧 HTML、历史运行目录、编辑中间脚本、浏览器资料、原卡完整 PNG 和未被构建引用的 observatory.jpg 均不进入交接包。已被当前构建引用的 assets/gray/v5 是素材集版本，保留它才能重建 V8。测试文件 v3.test.mjs 仍是当前回归套件的一部分。
- 工坊产物保留版本化文件与默认别名，因为原始清单分别校验。旧的源码接口格式、package.json 的 1.0.0 和项目所属的 V8 工坊版本各有自己的含义。
- handoff/source-inventory.json 保存导入时各原件的来源、字节数与哈希。为公开发布，兼容测试的机器路径改成可选环境变量；handoff/files.sha256 记录交接树的最终字节。新增开发入口与文档均在业务模块之外。
- ZIP 单独提供 SHA-256；Git 初始提交及标签可用随包的 Git bundle 恢复。
