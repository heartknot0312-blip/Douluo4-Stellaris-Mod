# 前端美化指南

当前主题叫“魂环星盘”：暗底金线的星盘册页。左侧九道魂环就是九个栏目，环色按魂环年限排列（百年黄、千年紫、万年黑、十万年红、百万年金）；星图以星盘刻度为底，领地用雕版排线区分阵营。机甲页沿用“图版目录”构图：六级机甲各占一列，选中的一列展开成主图并浮出规格卡。

打开预览后，先看星图（选中→看航程→再点一次进入），再看机甲图版和灰风窗口。这三处的动效最多，也最能检查主题是否一致。

## 材质与颜色

三层 CSS 的加载顺序为 atlas.css → flightdeck.css → command.css，由 scripts/build.mjs 合并进 atlas-style.generated.mjs。

- atlas.css：色彩变量、窗口外壳、九环导航、页脚滚动条、排版、面板、按钮、表单、弹窗与响应式断点。
- flightdeck.css：星图、右侧星盘册页、恒星系轨道盘、行星、舰船设计、斗铠与机甲图版、图鉴。
- command.css：外交、舰队、科技、养成、内政，以及灰风窗口与 L-星门调查。

颜色约定：

- 底色 `--bg` 近黑带紫；正文象牙色 `--ivory`，次级 `--ivory2/3`；描边与强调是金 `--gold`、`--gold2`。
- 魂环色只用于导航环、页面眉题罗马数字和当前栏目的 `--accent`，不要拿来表示状态。
- 阵营色来自 ui-model.factionOf：联邦冷蓝、龙马淡紫、游牧琥珀、海盗玫红；中立组织按业态区分（商业、学术、打捞等），未归属星域为冷灰。阵营同时用排线方向（联邦 45°、龙马 −45°、游牧交叉、海盗竖线、中立点阵）和名称区分，色弱用户不必只靠颜色。
- 状态色：可用/已掌握 `--ok` 青绿，警告 `--warn` 琥珀，危险 `--danger` 红。对玩家敌对用红色三角，生命信号用青绿圈，利维坦用洋红双圈，这三种标记形状不同。
- 不使用大圆角和玻璃拟态。面板是金色双线加四角括号，按钮是尖头切角。

## 字体

界面字体内嵌在脚本里（assets/fonts，见该目录 README）：`DL4 Serif`（Noto Serif SC 子集，900/600）、`DL4 Latin`（Cormorant Garamond）、`DL4 Latin SC`（Cormorant SC）。正文仍用系统黑体。运行时由 atlas.mjs 的 loadFonts 在打开窗口时经宿主文档 FontFace 注册，不访问网络。改了界面文字后运行 `python scripts/subset-fonts.py <原始字体目录>` 重新裁剪，否则新增字会回退系统字体。

## 动效

- 切换栏目时内容逐块浮现、标题逐字升起、带 `data-count` 的数字从零滚动；只在换页时触发（`.content.enter`，1.7 秒后移除），数据刷新不重播。
- 星图：星盘刻度缓慢自转并随平移视差；领地单元开场生长；航道先描一道亮线，再有光点沿航道流动（周期按航程）；选中星系时准星锁定。
- 机甲图版切换只改列宽与选中态，不重建页面。
- 系统开启“减少动态效果”时：CSS 动画压到瞬时完成，SMIL 光点、轨道小行星和舰影漂浮不创建（atlas.mjs 的 `still()`）。

## 兼容约束

样式位于 Shadow DOM；修改外层酒馆 CSS 不能替代组件样式。保留控件名称、键盘焦点、SVG 的点击热区和减少动效选项。让长中文名称、未知人口、零余额、大舰队与空档案参与验收。对预览的美术确认不能替代真实酒馆对脚本、变量和楼层重放的测试。

外观提交请避免同时改动 stat_data.星际、事务格式、知识投影、门槛与支付计算、旧档迁移，或原卡脚本标识和工坊哈希。若确实需要变更其一，应单独说明玩法影响并补相应回归。
