# 已实现与未完成功能

**交付点为 V8 开发快照。** 功能实现、模拟测试通过、真实酒馆内验收、用户确认美术效果是不同状态。

| 领域 | 工程内可用 | 尚待实测或完善 |
| --- | --- | --- |
| 导航 | 领地与航线、已知系统投影、可选择星系／行星、自绘轨道图、航程估算、生态与部署标记 | 密集节点文字避让、窄屏长列表、真实正文跨多轮发现后的连续性 |
| 外交、交易、内政 | 权限、好感、报价、服务、控制来源、资源及订单 | 独立酒馆中核查交易往返、迟到消息、长档授权与资金结算 |
| 战舰／舰队 | 分型船体、兼容插槽、图纸、委托、编队与整备；角色与自有舰船控制边界 | 大型编队、重复交付、装配平衡的实战体验。尚无已验收的连续战线推演或各回合交易收益历史图 |
| 装备／科研 | 双甲、整体机甲、等级与预览，科技前置及研究入口 | 自定义课题、特殊自研船体对完整 UI 的长档覆盖；模型深底和明亮主题衔接 |
| 伙伴／生态 | 四档生命、折叠图鉴、L-星门、灰风相认及好感、多伙伴事件 | 不同正文模型的遵循度、全部事件分支和重逢后长期互动 |
| 视觉 | 浅色舱框、多色栏目、九栏入口、局部仪表与依赖连线 | 全场景对比度、键盘巡检和移动端触摸验收，Owner 最终美术确认 |
| 发布 | 快照使用原工坊的作品及脚本格式，提供源码和预览 | 没有将 V8 视为稳定正式版。公共仓库的上传与分支保护由部署回执单独记录 |
