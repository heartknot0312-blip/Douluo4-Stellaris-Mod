# 项目架构说明

这是给 SillyTavern 角色卡安装的 Mod。玩家通过前端选择行动，行动进入正文；宿主收到回复后，后端解析事务并更新角色个人可知的世界。项目没有独立的账号服务器、云数据库或前端框架依赖。

| 层 | 维护位置 | 职责 |
| --- | --- | --- |
| 宿主集成 | src/browser-entry.mjs、src/host.mjs | 建立宿主适配器，初始化入口、订阅消息生命周期、读取和重放楼层状态，传送玩家确认的行动 |
| 状态与事务 | src/schema.mjs、src/engine.mjs、src/command.mjs | 表结构、种子、校验、原子提交、重放、研究与委托等指挥操作 |
| 正文与可见性 | prompts/、src/instruction.generated.mjs、engine.mjs 的 narratorContext 和 projectPlayer | 提示词与输出协议、主持人局部信息、供玩家消费的已知状态 |
| 世界内容 | src/content.mjs、src/public-atlas.mjs、src/l-gate.mjs、src/gray-content.mjs | 基础星域、研究与装备、太空生命、伙伴与事件 |
| 视图模型 | src/ui-model.mjs | 航程估算、装配计算、势力识别、装备套装、双甲协同 |
| 前端 | src/atlas.mjs、desk-panels.mjs、flightdeck.mjs、console-view.mjs、survey-globe.mjs | 浮窗、分栏、图表、恒星轨道与行星视图 |
| 打包 | scripts/build.mjs、scripts/build-gray-media.mjs、scripts/build-workshop.mjs | 内嵌脚本与素材、正则与世界书、兼容组件、作品和一键安装器 |
| 演示与验证 | scripts/preview.mjs、test/、scripts/verify.mjs | 通过合成场景挂载实际组件，执行规则、接口和产物校验 |

## 一次交互

1. browser-entry 挂载宿主适配器，mountAtlas 创建 Shadow DOM 并读取 getUIState()。
2. 选择恒星系、切换立绘或浏览科技只改变视图状态。需要进剧情的活动走 confirmAction。
3. 玩家确认后由适配器发起角色行动，并检查聊天与楼层上下文。正文结算写入 DL4Space。
4. engine 提取事务，校验引用、所有权、约束和事件前置，再向存档提交。重放处理换楼、分支、重试等情形。
5. UI 订阅刷新，再次从玩家投影读取。离线预览向 previewActions 记录请求，不能代表实际模型已正确生成事务。

## 依赖与版本

JavaScript 使用 ES modules。运行时通过项目自有的有序文件清单打为单个脚本；打包器去除单行 import 和 export，因此新增模块须同时更新 build.mjs、preview.mjs 的清单并保持顺序兼容。恒星系轨道图为项目自绘 SVG，不再随包携带 WorldOrbit。界面字体子集与机库图由 build.mjs 以 base64 写入 fonts.generated.mjs、hangar.generated.mjs。部署基线在 outputs/manifest.json。宿主通过 MVU 读取消息变量，角色专属 UI 偏好与剧情的权威状态分别处理。
