# 本地运行指南

## 修改前端和预览

1. 解压整个 ZIP，在包含 package.json 的目录打开终端。环境为 Node.js 22 或以上；已用 Node.js 24.22.1 验证。此项目没有需要从 npm 安装的运行依赖。原工程没有 npm 锁文件。
2. 运行 `node handoff/preview.mjs`。默认访问 http://127.0.0.1:8766/。如端口被占用，可在 PowerShell 中先设置 `$env:PORT='8876'`。
3. 预览启动器把 src、assets、scripts、prompts 复制到临时目录，重新执行原构建与预览脚本，只提供生成的页面。修改源码后按 Ctrl+C 停止并重启。outputs/星海导航-预览.html 可直接双击打开。
4. 网页中的场景选择器可切换星门调查、开启、探索、重逢。关闭浮窗即可操作页面顶部演示控件，再点击导航入口。使用“满好感”按钮检查婚纱解锁。

## 回归和发行构建

在根目录运行 `node --test test/*.test.mjs`，并用 `node scripts/verify.mjs` 核查已有产物。测试夹具可按条件跳过，终端会报告数量。完整工作区曾保留的 V6 安装器仅供跨版本测试；交接工程不收录该旧发行包。若需运行本地 Zod 形状测试，设置 SILLYTAVERN_ROOT 指向装有相容 zod 的酒馆目录。

要重建工坊发行物，先在一个独立副本中执行：

```sh
node scripts/build.mjs --card "/path/to/compatible-original.png"
node scripts/build-workshop.mjs
node scripts/preview.mjs --build-only
node scripts/validate.mjs
```

build.mjs 会检查原卡 SHA-256，抽出原版 ZOD 并添加星际与星际待办字段。安装器还读取 work/workshop/entry.js。原始人物卡 PNG 需由维护者自行提供。前端开发可以用合成存档离线预览。直接运行基础 build 后会重写 outputs/manifest.json，按上述顺序生成完整工坊清单。

.env.example 说明两个可选变量。Node 默认不会自动加载 .env。完整酒馆联调时，使用角色卡副本和独立聊天，检查从游戏操作发起正文、AI 输出、事务结算、状态刷新、换聊天以及回退消息的行为。
