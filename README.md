# 斗罗大陆4群星 Mod · V9 魂环星盘

在 SillyTavern 的《斗罗宇宙》角色卡中扮演一名进入太空的角色。个人能够乘船旅行、参与贸易、委托建舰，在探索中认识灰风等伙伴。星图随正文中已经获得的情报更新。

V9 的星海导航采用「魂环星盘」界面，包含九道魂环导航、星系档案、机甲图版和 L 星门线索盘。工坊版本为 9，前端版本为 9.0.0，后端数据格式为 1.0.0。

## 先看界面

双击 [离线预览](outputs/星海导航-预览.html)。要修改页面，请安装 Node.js 22 或以上版本，在仓库根目录运行下列命令，访问终端显示的本机地址。预览离线运行，演示消息使用合成存档。

```sh
node handoff/preview.mjs
```
